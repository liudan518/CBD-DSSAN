Make rare faults visible.

When healthy data vastly outnumber faults, a high-accuracy classifier can still overlook the events that matter. CBU-DSSAN combines representative downsampling with Siamese self-attention to learn a more discriminative fault space.

01 / THE CHALLENGE

The imbalance is the problem.

Rare fault patterns are overwhelmed by healthy operating history. A useful detector must preserve the minority signal without losing representative normal conditions.

01

Healthy data dominate learning

In the first training fold, 787 normal samples compete with 30 EIF and 20 TSIF samples. The network may optimize normal accuracy and miss uncommon faults.

02

Fault records cannot be discarded

Random resampling can remove valuable evidence. The proposed approach clusters only the normal majority and retains every observed fault sample.

03

Overall accuracy can mislead

On the first test fold, a detector that calls all 210 samples normal would still reach 93.81% accuracy, despite detecting no faults.

02 / DATA & EVALUATION

Operational evidence, not synthetic examples.

The study uses gas-turbine monitoring data from an Asian airline, collected during 2003–2012. Four condition indicators are processed using 10-cycle sliding windows and evaluated with five-fold cross-validation.

The four channels are EGTM, DEGT, DN2 and DFF. The dataset contains 984 normal, 38 exhaust-gas-temperature indication fault (EIF), and 25 total-air-temperature sensor indication fault (TSIF) samples.

03 / THE APPROACH

Compress the majority. Learn the boundary.

CBU-DSSAN does not synthesize extra fault examples. It creates a representative, more balanced training set and learns similarity through a shared-parameter Siamese network.

01

Cluster normal samples

Use k-means on normal training data; cluster centers represent redundant healthy patterns.

02

Construct training pairs

Pair representative normal features with intact EIF and TSIF samples, creating same-class and different-class pairs.

03

Learn Siamese embeddings

Shared self-attention encoders extract temporal features; contrastive loss separates classes in the learned space.

04

Classify by distance

A test sequence is assigned through proximity to labeled support samples in feature space.

↗

Model configuration

The reported implementation uses two encoder blocks, four attention heads, model dimension 64, Adam learning rate 2×10⁻⁴ and batch size 128. Five-fold evaluation is used.

04 / REPORTED RESULTS

Measure the minority, not just the average.

Balanced accuracy gives normal, EIF and TSIF recalls equal importance. In the paper’s five-fold comparison, CBU-DSSAN achieved the highest average balanced accuracy among the reported methods.

06 / DESIGN SENSITIVITY

How many normal prototypes?

The authors varied the number of normal cluster centers from 20 to 50. Thirty centers delivered the highest reported five-fold average balanced accuracy (92.26%).

Preserve every fault. Reduce redundant normal history.

The central idea is to confront both imbalance and class overlap: retain rare fault evidence, compress the normal majority, and train a metric space in which classes are easier to distinguish.

abstract = {For highly reliable gas turbines that rarely suffer faults, the overwhelming majority of historical data are collected under healthy state, while only a very small number of them are fault samples. However, traditional deep neural networks pay most attention to normal samples, resulting in a high missing diagnostic rate for fault samples. To address this problem, this paper develops a new fault diagnosis framework that integrates clustering-based downsampling with deep Siamese self-attention network (CBU-DSSAN), to reduce the number of normal training samples via clustering and strengthen the ability of fault feature extraction via multi-head self-attention mechanism. First, clustering-based downsampling is only conducted on the normal samples, and the cluster centers are put together with the fault samples to serve as the training data set, in order to balance the normal and fault classes. Second, the Siamese network maps the original data set into an embedded feature space, in which fault samples and normal samples belonging to different classes are far away from each other. Finally, the performance of the developed CBU-DSSAN has been evaluated using actual monitoring data of gas turbines.}
